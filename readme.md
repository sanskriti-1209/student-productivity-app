# Student Productivity App

A simple and user-friendly web application designed to help students organize their daily tasks, manage their time, and stay productive.

## Features

* 📝 **Task Management** – Add, manage, and track daily tasks.
* ⏰ **Time Management** – Helps students stay focused and manage their study time.
* 📊 **Productivity Tracking** – Monitor your progress and completed tasks.
* 🎯 **Simple Dashboard** – View important productivity information in one place.
* 📱 **Responsive Design** – Works smoothly on both desktop and mobile screens.
* 🎨 **Clean & User-Friendly Interface** – Designed to make productivity management simple and easy.

## Tech Stack

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript** – Functionality and interactivity

## How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/sanskriti-1209/student-productivity-app.git
```

2. Open the project folder:

```bash
cd student-productivity-app
```

3. Open `index.html` in your browser.
